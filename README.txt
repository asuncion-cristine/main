HOW TO INSTALL
1. Unzip this file.
2. Copy EVERYTHING inside the "site" folder into your project folder
   (the same folder where your old index.php is). Choose "Replace" when asked.
3. The "includes" folder must end up like this:
      your-project/includes/header.php
      your-project/includes/footer.php
      your-project/includes/content.php
   Delete any OLD includes/header.php or footer.php first if the error continues.
4. Run the site again and refresh (Ctrl+F5).

Edit your name and Facebook/Instagram links in includes/content.php
